## Quick Commands
- `npm run build` : tsdown bundle build (ESM/CJS/IIFE/DTS)
- `npm test` : Run the Vitest harness (8 target environments + dynamic fuzzing)
- `npm run typecheck` : `tsc --noEmit`
- `npm run lint` : ESLint check (`src`, `tests`)
